# ONSO Interior — 인테리어 업체 홈페이지 (포트폴리오)

홈페이지 제작 포트폴리오용 **가상 인테리어 업체** 원페이지 사이트입니다.
업체 정보·후기·수치는 예시이며, 모든 공간 사진은 Higgsfield(GPT Image 2.6)로 생성했습니다.

## 주요 기능
- 풀스크린 히어로 + 스크롤 등장 애니메이션
- 평형별 필터가 있는 포트폴리오와 상세 팝업
- **예상 견적 계산기** — 평형 × 시공 범위 × 마감 등급 → 비용·기간, 결과를 상담 폼에 자동 입력
- 상담 신청 폼(데모, 전송 없음) · 연락처 자동 하이픈 · 입력 검증
- 모바일 하단 고정 상담 바, 반응형(375px~)

## 기술
HTML · CSS · Vanilla JS (빌드 없음) / GitHub Pages 배포
